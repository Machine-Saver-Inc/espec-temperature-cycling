# Icons

Every mark in this folder is from **Lucide** (https://lucide.dev), the icon
set shadcn/ui uses, vendored from `lucide-static` v1.47.0 and unchanged
apart from having the web-only `class` attribute removed.

The file name is the name a button asks for; the Lucide name it came from
is below. Add a row here whenever a new button earns a new mark.
